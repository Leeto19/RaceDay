 # RaceDay

## System Description

RaceDay is a race event management system designed to manage organisers, participants, events, categories, enrolments and race results. The system uses a relational SQL Server database and is planned to be accessed through a RESTful API.

## User Roles

### Organiser

An Organiser can manage race events and categories and view/manage participant enrolments and results.

### Participant

A Participant can register and log in, manage their profile, view available events and categories, enrol for events and view their race results.
